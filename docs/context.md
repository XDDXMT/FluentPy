# FluentPy Context

FluentPy is an independent MIT-licensed Fluent-inspired UI toolkit for Qt for Python.

The project is not a fork of qfluentwidgets and should not copy its source code, assets, stylesheets, documentation, examples, module structure, or API signatures.

## Product Direction

- Commercial-use friendly MIT license.
- PySide6 first, with a backend facade for future PyQt6 support.
- Native API should stay independent.
- Migration support should exist as tooling or optional compatibility packages, not as the main project identity.

## First MVP

- Project metadata and MIT license.
- PySide6 backend facade.
- Theme manager with light and dark modes.
- Runnable gallery window.
- First controls: buttons, toggle switch, slider, progress bar, line edit, toast, and window shell.
